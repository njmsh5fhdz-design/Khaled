DRABOKA Website
================
ملفات الموقع:
- index.html
- style.css
- script.js
- draboka-logo.jpg

طريقة التشغيل:
افتح index.html في المتصفح.
للنشر على الاستضافة: ارفع الملفات الأربعة إلى public_html أو مجلد الموقع.

التعديلات المطلوبة مطبقة:
- استخدام لوجو DRABOKA المرفق
- بدون أسعار
- بدون "قهوتك على إيقاع الليل"
- حذف مشروبات الدربوكة المميزة
- إضافة عصائر وسموزيهات
- حذف براونيز وتشيز كيك وكوكيز
- إضافة كسكسي، حمص الشام، أم علي، وافل
- تصميم Responsive للموبايل والكمبيوتر
